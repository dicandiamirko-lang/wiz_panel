# Security Policy

Questo repository contiene un ambiente di esercitazione (Wiz Technical Exercise)
con **debolezze di configurazione intenzionali**, documentate nel [README](README.md):
SSH esposto, bucket pubblico, versioni obsolete di Linux e MongoDB, permessi eccessivi.
Queste non vanno segnalate come vulnerabilità.

## Come segnalare una vulnerabilità

Per qualunque altro problema di sicurezza (per esempio un segreto esposto o un
difetto nelle pipeline) usa la segnalazione privata di GitHub:
**Security → Report a vulnerability**.

Non aprire issue pubbliche per problemi di sicurezza.

## Versioni supportate

È supportato solo il branch `main`.
